# Архив, баримт бичигтэй ажиллах арга зүй (E.DW416)

E.DW416 хичээлийн агуулгыг 3 бүлэг, 16 сэдвээр дарааллаар нь судалж,
баримт бичгийн алдааг олж засах дадлага хийж, давтах цагаа SMS-ээр
сануулуулдаг нэг хуудас вэб. Сервер, бааз шаардахгүй.

## Яаж ажиллуулах

1. `index.html`-ийг браузерт давхар товшиж нээнэ.
2. Тест: `npm test` (одоохондоо тест байхгүй)

## Агуулга нэмэх заавар

1. `data.js`-ийг текст засварлагчаар нээнэ (Notepad, VS Code г.м).
2. Тухайн сэдвийн мөрийг олно, жишээ нь `{ id: 5, chapter: 2, ... }`.
3. Хоосон талбаруудыг бөглөнө:
   - `title`: сэдвийн нэр
   - `goal`: сэдвийн зорилго
   - `concepts`: гол ойлголтууд, `["...", "..."]` хэлбэрээр
   - `lecture`, `seminar`: лекц, семинарын агуулга. Догол мөр бүрийг `\n\n`-ээр тусгаарлана.
   - `references`: хууль, стандарт, `[{ title: "MNS 5140:2026", clause: "4.2" }]` хэлбэрээр
   - `clo`: хоосон бол бүлгийн CLO харагдана.
4. Хадгалаад браузераа шинэчилнэ (F5). Бүх талбар нь хоосон сэдэвт
   "Удахгүй нэмэгдэнэ" гэж гарна.

Текстийг `"..."` хашилтад бичнэ. Текст дотор `"` орвол `\"` гэж бичнэ.
