# Архив, баримт бичигтэй ажиллах арга зүй (E.DW416) — суралцах вэб

E.DW416 хичээлийн оюутнуудад зориулсан
унших, лавлах вэб. Сервер, бааз шаардахгүй.

## Хэсгүүд

| Хэсэг | Агуулга | Хаяг |
|---|---|---|
| Лекц | 8 лекц (тус бүр 90 минут, 2 долоо хоног): зорилго, гол ойлголт, агуулга, холбогдох эрх зүйн акт | `#lekts-1` … `#lekts-8` |
| Семинар | 16 семинар: зорилго, урьдчилан бэлтгэх, хийх ажил, бүтээл, бие даалт | `#seminar-1` … `#seminar-16` |
| Эрх зүйн сан | Хууль, журам, стандарт: огноо, дугаар, статус, legalinfo.mn / estandard.gov.mn холбоос | `#erh-zui` |
| Лавлах | 31 нэр төрөл, 28 бүрдэл, хэвлэмэл хуудсан дээрх байршил | `#lavlakh` |
| Зураглал | Хичээлийн оюуны зураглал (`mindmap.html`) | `#zuraglal` |
| Миний явц | Уншсан лекц, семинар, нийт болон бүлгийн дүүрэх зурвас (энэ төхөөрөмж дээр хадгална) | `#miniy-yavts` |

## Файлууд

- `index.html`: хуудасны бүтэц
- `style.css`: загвар (утас, бараан горим)
- `app.js`: Лекц, Семинар, Эрх зүйн сан, Зураглал, Миний явц хэсгийг зурах, шилжих
- `progress.js`: явцын дүрмүүд (`window.PROGRESS`), localStorage-д хадгална
- `lectures.js`: 8 лекцийн агуулга (`window.COURSE`)
- `seminars.js`: 16 семинарын мэдээлэл (`window.SEMINARS`)
- `laws.js`: эрх зүйн сан (`window.LAWS`), статусыг шалгасан огноо `CHECKED`
- `docs-data.js`, `docs-view.js`: Лавлах хэсэг (31 нэр төрөл)
- `mindmap.html`: оюуны зураглал (бие даасан хуудас)
- `test/content.test.js`: агуулгын өгөгдлийн тест
- `test/docs.test.js`: Лавлахын өгөгдлийн тест
- `test/progress.test.js`: явцын дүрмийн тест
- `mongol_tsegtslal.md`: монгол бичвэрийн цэг таслалын дүрэм
- `.claude/commands/hyanalt.md`: байршуулахын өмнөх хяналт (`/hyanalt` command)

## Яаж ажиллуулах

1. `index.html`-ийг браузерт давхар товшиж нээнэ.
2. Тест: `npm test` (Node 18+)

## Байршуулах (GitHub Pages)

1. Файлуудыг репозиторийн үндсэн хавтсанд хуулж commit, push хийнэ.
2. GitHub → Settings → Pages → Source: "Deploy from a branch", Branch: `main`, хавтас `/ (root)`.
3. Хэдэн минутын дараа `https://<хэрэглэгч>.github.io/<репозитори>/` хаягаар нээгдэнэ.
   Үнэгүй багцад репозитори public байх шаардлагатай.

## Агуулга засах

- Лекц: `lectures.js`-ийн тухайн лекцийн `sections` дотор блок нэмнэ:
  `{ p: '...' }`, `{ ul: ['...'] }`, `{ ol: ['...'] }`,
  `{ table: { head: ['...'], rows: [['...']] } }`, `{ note: '...' }`.
- Эрх зүйн акт нэмэх: `laws.js`-ийн `items`-д мөр нэмж, лекцийн `laws` жагсаалтад `id`-г бичнэ.
- Статус шинэчлэх: `status`-ийг "хүчинтэй", "шалгах", "хүчингүй"-гийн аль нэгээр,
  `CHECKED` огноог шинэчилнэ.
- Текстэд "" хашилт хэрэглэнэ («» хэрэглэхгүй; тест шалгана).
